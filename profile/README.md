# C++ for BPF

cpp-bpf is an open source project to make C++ a practical and reliable
language for writing BPF programs, building on clang and libbpf rather than
replacing them.

The project is at an early stage: the current work is compiler support for
C++ records in LLVM's BPF backend. The library, examples and project
template will follow.
